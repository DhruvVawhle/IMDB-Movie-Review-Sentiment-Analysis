🎬IMDB Movie Review Sentiment Analysis

A Machine Learning and Natural Language Processing (NLP) project that classifies IMDB movie reviews as Positive or Negative using the IMDB Dataset of 50K Movie Reviews from Kaggle. The project demonstrates the complete NLP pipeline, including text preprocessing, exploratory data analysis (EDA), feature extraction, model training, evaluation, and performance comparison.

📌 Overview

Sentiment Analysis is a Natural Language Processing (NLP) task used to determine the sentiment expressed in textual data. This project builds a binary sentiment classification model capable of predicting whether an IMDB movie review conveys a positive or negative opinion.

The project follows a complete machine learning workflow—from data preprocessing and visualization to feature engineering, model development, and evaluation—providing practical insights into text classification using Python.

📂 Dataset

Dataset: IMDB Dataset of 50K Movie Reviews

The dataset contains 50,000 labeled movie reviews equally distributed between Positive and Negative sentiments. It is one of the most widely used benchmark datasets for binary sentiment classification.

Source:
https://www.kaggle.com/datasets/lakshmi25npathi/imdb-dataset-of-50k-movie-reviews
